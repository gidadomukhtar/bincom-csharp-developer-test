# Bincom C# Developer Trainee Assessment

A C# console application developed as part of the preliminary technical assessment for the **.NET C# Developer Trainee (Internship)** position at Bincom Dev Center.

## 📌 Assessment Overview

This project demonstrates fundamental C# programming concepts, including:

- Variables and data types
- Console input and output
- Conditional statements
- For loops
- Foreach loops
- Arrays
- Methods and parameters

## 🛠️ Technologies Used

- **C#**
- **.NET**
- **Visual Studio Code**
- **.NET CLI**

🧩 Tasks Implemented
Task 1 — Variables and Data Types

The application declares and initializes:

A string variable for a name
An int variable for age
A bool variable for administrator status

The values are then displayed in the console.

Task 2 — Even or Odd Number

The application accepts an integer from the user and uses an if-else statement to determine whether the number is Even or Odd.

Task 3 — For Loop

A for loop is used to display the numbers from 1 to 10.

Task 4 — Arrays and Foreach Loop

The application works with the following integer array:

int[] numbers = { 2, 4, 6, 8, 10 };

It calculates the sum of the elements and uses a foreach loop to display each element.

Task 5 — Method and Parameter

A method named Greet accepts a string parameter and displays a personalized greeting.

Example:

Greet("Alice");

Output:

Hello, Alice!
